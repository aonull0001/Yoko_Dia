# 横浜鉄道ダイヤグラム

React + TypeScript + SVGによるブラウザー内ダイヤ編集アプリです。列車データはIndexedDBに保存され、外部サーバーへ送信されません。外部フォントも読み込みません。

## 開発

```sh
npm ci
npm run dev
npm test
npm run build
```

GitHub Pages向けのbase pathは `/Yoko_Dia/` です。`.github/workflows/deploy.yml` は `main` へのpush後にテスト・ビルド・Pages公開を実行します。公開にはリポジトリへのpush権限とGitHub Pages設定が必要です。

## 操作

- 「列車追加」から列車を作成し、時刻・停車/通過・番線・列番を編集します。
- ダイヤ上はクリックで選択、ダブルクリックまたは右クリックで詳細編集を開きます。列車線のドラッグは全時刻、停車点のドラッグは該当駅の時刻を移動します。不整合が生じるドラッグは確定されません。
- `Delete`で選択列車を削除、`Ctrl+Z` / `Ctrl+Y`で編集履歴を移動、`Ctrl+S`でIndexedDBへ保存します。
- 「開く」からYTDを読み込むか、Excelを取り込みます。Excelはシートと列車のプレビューを確認してから現在のデータへ追加します。
- YTD・CSV・ダイヤPNGをダウンロードできます。スタフは運用ごとまたは全運用でブラウザーの印刷画面を開き、「PDFとして保存」を選択します。
- 同じ列番の列車を運用単位にまとめ、詳細の「運用順」で順番を指定します。列番未設定列車は別々に扱います。

## データ形式・制約

- 駅マスターは東神奈川・大口・横浜ゲートウェイ・菊名・新横浜・小机（駅番号1〜6）です。
- 種別・行先番号は `A + 種別番号 + 終着駅コード` として表示し、列番とは独立して保存します。添付Excelの規則では種別6/7/8が各駅停車/快速/特別快速、終着駅コード1/2/3/4が東神奈川/横浜ゲートウェイ/新横浜/小机です。
- `Yoko_Dia.xlsx` の実シートを確認し、「表からスタフ」の列番1201A（A61、下り、種別6）を取り込む専用処理を実装しました。方向別シートも列番が入力された列を取り込みます。確認したファイルの「下り」「上り」はそれぞれ24列の列番が空欄で全列同一の既定テンプレート値だったため、列車として誤登録せず、プレビューに警告を表示します。
- Excel数式はブラウザー上で実行せず、ファイルに保存された計算済みセル値を取り込みます。数式の再実装ではなく、既定の計算結果を実データと照合したものです。
- 駅間所要時間の汎用計算関数は入力された走行・停車秒の単純な累積計算です。Excelの全数式をTypeScriptへ移植したものではありません。
- 整合性チェックは時刻逆転、長い駅間時間、番線/区間の重複、近接列車、運用接続の要確認箇所を示します。閉そく・分岐器・線路構造がないため、安全判定ではなく運行上の安全性を保証しません。
- PDFはブラウザーの印刷機能を使います。日本語表示はブラウザー/OSにあるフォントに依存します。
- YTDは形式バージョン1です。旧ファイルは欠落フィールドの補完を試みますが、未知の過去形式すべてとの互換性は保証しません。
- 実データのExcel/YTDファイルはアプリや公開リポジトリに同梱せず、利用者がローカルから読み込みます。列車データはブラウザー内に保存され、外部へ送信されません。
